GPG Master Guide

A step-by-step framework for Windows, Mac, and Linux users on how to install, manage keys, and execute secure cryptographic transactions.

1. Installation Across Platforms

Depending on your operating system, setup your environment using the appropriate method:

  • Windows: Download and run the official installer from Gpg4win.org (bundles Kleopatra GUI and command-line utilities).
  • macOS: Open your Terminal and install via Homebrew using brew install gnupg.
  • Linux: Utilize your native package manager (e.g., sudo apt install gnupg for Ubuntu/Debian or sudo dnf install gnupg for Fedora).

2. Generating Your Key Pair

Open your command line interface and execute the key generation wizard:

gpg --full-generate-key
  • Select option 1 (RSA and RSA).
  • Choose a robust key length of 4096 bits.
  • Set an expiration date (e.g., 1 or 2 years) for forward security hygiene.
  • Input your Real Name, Email Address, and a secure passphrase.

3. Key Exchange Etiquette & Verification

Before executing secure messaging transactions, safety requires verifying identities properly.

  • Export Public Key: Run gpg --armor --export your_email@example.com > my_pubkey.asc and transmit the text file to your partner.
  • Import Partner Key: Import received keys locally via gpg --import partner_pubkey.asc.
  • Verify Fingerprints (Crucial): Never trust raw downloads blindly. Cross-check the cryptographic fingerprint out-of-band via phone or separate secure channel: 
    gpg --fingerprint partner@example.com
  • Sign the Key: Once verified, establish web-of-trust validation by signing their key: 
    gpg --sign-key partner@example.com

4. Encrypting and Decrypting a Transaction

With keys successfully shared and verified, you can now process secure transaction flows.

  • Encrypting Data: Create a plaintext document named transaction.txt, then encrypt it targeted to your partner's identity: 
    gpg --encrypt --recipient partner@example.com transaction.txt
    This outputs a secure ciphertext file transaction.txt.gpg ready for transit.
  • Decrypting Data: Upon receiving an incoming .gpg file, decode it using your private key: 
    gpg --decrypt transaction.txt.gpg > decrypted_transaction.txt
    Enter your secret passphrase when prompted to safely unveil the plaintext.
